# Cinder Coffee — HTML версия

Статический HTML/CSS/JS сайт кофейни с моушн-дизайном.

## Как открыть

Просто откройте `index.html` в браузере. Никакой сборки не требуется.

## Деплой на GitHub Pages

1. Загрузите все файлы в репозиторий
2. Settings → Pages → Source: Deploy from a branch → main / root
3. Сайт будет доступен по ссылке `https://username.github.io/repo-name/`

## Стек

- HTML5 + Tailwind CSS (CDN)
- GSAP + ScrollTrigger (CDN) — анимации
- Vanilla JS — интерактивность

## Структура

```
index.html          # главная страница
css/style.css       # стили
js/main.js          # анимации и логика
images/             # фото (Unsplash) + логотип
```
